FUN – napojení na hlavní web (4 malé úpravy tvých stávajících souborů)

1) index.html
   a) mezi ostatní <link rel="prefetch"> přidej:
      <link rel="prefetch" href="fun.html">
   b) nahraď celé první písmeno (F) tímhle:
    <a class="letter" style="--i: 0" href="fun.html" data-t="green" data-face="red" aria-label="F, Fun">
      <span class="tilt"><span class="stack"><svg class="f" viewBox="0 0 70 100"><path fill-rule="evenodd" d="M0 0H70V20H20V40H58V60H20V100H0Z"/></svg></span></span>
      <span class="tag" data-x="Fun">Fun</span>
    </a>

2) transition.js – v řádku s  var OWN = {...}  přidej na konec (před }) :
   , "fun.html": "M0 0H70V20H20V40H58V60H20V100H0Z"

3) style.css – úplně na konec souboru vlož:
@media (prefers-reduced-motion: no-preference) {
  html[data-vt="fun"]::view-transition-old(root),
  html[data-vt="fun"]::view-transition-new(root) { animation-delay: 0.5s; animation-fill-mode: both; }
  html[data-vt="fun"]::view-transition-group(letter) { animation-duration: 0.75s; animation-delay: 0.5s; }
  html[data-vt="fun"]::view-transition-image-pair(letter) { animation: gl-pair 1.25s step-end both; }
  html[data-vt="fun"]::view-transition-old(letter) { animation: gl-old 1.25s step-end both; mix-blend-mode: normal; }
  html[data-vt="fun"]::view-transition-new(letter) { animation: gl-new 1.25s step-end both; mix-blend-mode: normal; }
}

4) Nahraj do hlavní složky: fun.html, fun.js, fun3d.js, fun-data.js, fun-print.jpg

Pozn.: sdílecí obrázek (og-image) má pruh F pořád červený – až bude čas, přebarvíme na zelený.
